# One public demo path: a slate under pressure

In this working copy, open the [saved New York decision](/judge.html#bf9b65d52eeff00e0e258917) on the running application. Production needs a separate authorized deployment. This path requires no login and makes no provider calls. It replays saved Qloo research; it is not a fresh live-agent run.

1. **Review the brief.** Read the selected acts and the visible slot, fee-budget, genre and discovery constraints. The fees, availability and genres are illustrative buyer inputs. The recorded research path links each Qloo stage to reduced public receipts.
2. **Isolate Qloo evidence.** Select **Compare with Qloo evidence removed**. The side-by-side result keeps the candidate pool, fees, availability, policy and constraints fixed. New York changes its selected lineup; Berlin, if opened as a second example, does not. Inspect linked receipts and the individual-signal tests in Proof Lab. This is an internal optimizer counterfactual, not measured commercial value.
3. **Apply pressure.** Select **Cut budget below this lineup’s cost**. Show the recomputed feasible slate or explicit infeasibility, then the saved original LLM selection checked against the same budget. The LLM was not re-prompted for this click.
4. **Show the broader stress result.** Open the [shock benchmark](../results/shocks.md). Read its 12-candidate headline with the denominator and synthetic label. Show the three saved re-prompts per shock, budget-overage amounts and abstentions. The optimizer's zero proposed-lineup violations follow from its constraint design.
