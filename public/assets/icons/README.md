Pinned upstream revision: `2b75f3ad12b420c9504ef05df8d2564a28f8500e`. Source SVG paths and geometry are unmodified; application filenames preserve the existing icon keys. Navigation and decision symbols use duotone; compact actions use bold. CSS alpha masks retain the source opacity and inherit the surrounding text color.

Icons are decorative and hidden from assistive technology. Labels and accessible names remain in HTML. No package, font, CDN or runtime dependency is required.
