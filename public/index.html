    Know what the evidence can say.

    Cultural affinity does not measure net-new ticket buyers, guarantee sell-through, or establish commercial availability. Artist fees, availability, and genre categories are booking inputs. The optimizer’s utility score is a decision heuristic, not a probability or forecast.

    Synthetic mode is a reproducible product demonstration. Every run and export identifies its data source. Live mode requires a Qloo API key on the server.
